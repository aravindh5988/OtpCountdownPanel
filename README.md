# OTP Countdown Panel

This Mendix web widget counts down to a configured Date Time attribute. When the deadline is reached, it can run an optional action and display nested content. The countdown’s days, hours, minutes, and seconds can be shown or hidden. Its page content is not individually editable in a presentation unless exported separately.

## Dependencies

- Mendix Studio Pro with support for pluggable web widgets
- Mendix Pluggable Widgets Tools 11.12.1
- A Mendix page with an entity context and a Date Time attribute for the deadline

## Configuration

- Add the OTP Countdown Panel to a page with an entity context.
- Select the Date Time attribute that sets the countdown deadline.
- Choose which time units to display.
- Optionally configure the When done action.
- Add widgets to After countdown completes if you want content to appear when the deadline is reached.
- Build the widget package and import it into Studio Pro.
